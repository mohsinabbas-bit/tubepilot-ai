HOW TO UPLOAD (GitHub)

1. Open your GitHub repo (the one that hosts tubepilotai.app).
2. DO NOT DELETE the existing CNAME file on GitHub.
3. Upload / replace these from this folder (overwrite older files):
   - index.html
   - site.css
   - main.js
   - privacy.html
   - terms.html
   - site.webmanifest
   - robots.txt
   - sitemap.xml
   - .nojekyll
   - ALL screen-*.png (including NEW: screen-keywords.png, screen-team.png)
   - icons if missing
4. Keep the approve/ folder (or re-upload approve/).
5. Wait 1–5 minutes, then open https://tubepilotai.app/
